# Supabase migrations

Esta e a pasta oficial de migrations do Supabase no MedQuiz.

- Versione novas migrations em `supabase/migrations/` antes de executar.
- A pasta `migrations/` na raiz esta sendo descontinuada.
- Nao execute migrations sem revisar o SQL e confirmar o ambiente alvo.
- O arquivo `supabase/config.toml` deve ser criado futuramente com `supabase init`, quando a Supabase CLI estiver instalada/configurada.
